Penjelasan Kode
![alt text](https://github.com/sleepnpeace/Studi_Kasus_5_DDP_Rafik_Anugrah_Yana/blob/main/images/1.png)

Kode ini berisi function dengan nama hitung biaya parkir dan didalam nya terdapat 2 parameter yaitu jenis kendaraan(untuk menyimpan jenis kendaraan yang dipilih) dan lama parkir(untuk menyimpan berapa lama kendaraan di parkir). jadi, function ini digunakan untuk proses menghitung biaya parkir nanti 

![alt text](https://github.com/sleepnpeace/Studi_Kasus_5_DDP_Rafik_Anugrah_Yana/blob/main/images/2.png)

Kode ini digunakan untuk menentukan tarif berdasarkan jenis kendaraan. Jika kendaraan adalah Mobil, maka tarifnya Rp5.000 per jam, sedangkan jika kendaraan adalah Motor, tarifnya Rp3.000 per jam. jika selain kedua kendaraan tesebut function akan mengembalikan nilai 0

![alt text](https://github.com/sleepnpeace/Studi_Kasus_5_DDP_Rafik_Anugrah_Yana/blob/main/images/3.png)

Kode ini digunakan untuk menghitung total biaya parkir dengan mengalikan tarif dan lama parkir lalu return untuk mengembalikan hasil perhitungan biaya parkir dari dalam function

![alt text](https://github.com/sleepnpeace/Studi_Kasus_5_DDP_Rafik_Anugrah_Yana/blob/main/images/4.png)

Kode ini berfungsi agar pengguna dapat menginput jenis kendaraan, jam masuk (menggunakan tipe data interger) dan jam keluar (menggunakan tipe data integer)

![alt text](https://github.com/sleepnpeace/Studi_Kasus_5_DDP_Rafik_Anugrah_Yana/blob/main/images/5.png)

Kode ini berfungsi menghitung berapa lama parkir dengan cara mengurangi jam keluar dengan jam masuk dan memanggil function hitung biaya parkir dengan memberikan dua data yaitu jenis sebagai jenis kendaraan dan lama_parkir sebagai durasi parkir yang kemudian hasil perhitungan disimpan dalam variabel total dan dapat digunakan untuk menampilkan total biaya

![alt text](https://github.com/sleepnpeace/Studi_Kasus_5_DDP_Rafik_Anugrah_Yana/blob/main/images/6.png)

Kode ini berfungsi untuk menampilkan headline hasil parkir, jenis kendaraan, jam parkir, jam masuk, dan lama parkir dari hasil pengurangan jam keluar dengan jam masuk, dan total biaya dari hasil perhitungan variabel total tadi
